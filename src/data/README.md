# Neighborhood snapshot

`neighborhood.json` is a derived OpenStreetMap database under ODbL, © OpenStreetMap contributors. See `../../public/SOURCES.md` for source URLs, retrieval date, transformations, dimensions, attribution and modeling limitations.

Coordinates are local metres `[east, south]` relative to the official project pin. `points` preserves way outlines / lines; closed multipolygon relations also include `holes`. Tags are reduced to those needed for rendering and building information. The runtime does not call a map provider or require an API key.
